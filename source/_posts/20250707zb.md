## 什么是多流推送

直播场景中，主播经常需要**把同一个画面同时推送到多个平台**（如 B 站 + 抖音 + 视频号）。OBS 官方原版只支持推流到单个平台，多平台就得靠第三方插件 **obs-multi-rtmp** 实现。

obs-multi-rtmp 是社区开源插件（sorayuki/obs-multi-rtmp），支持在 OBS 里添加**多路 RTMP 输出**，每路独立配置推流地址和码率，互不影响。

## 一、下载与安装

**官方资源**：

- 插件项目：[obs-multi-rtmp](https://sorayuki.github.io/obs-multi-rtmp/)
- 下载地址：[GitHub Releases](https://github.com/sorayuki/obs-multi-rtmp/releases)
- OBS Studio：[OBS 官网下载](https://obsproject.com/download)

### Windows 安装

1. 下载 `obs-multi-rtmp-x.x.x.x-windows-x64.zip`；
2. 解压后把 `data` 文件夹中的文件，复制到 OBS 安装目录的 `data` 文件夹中；
3. 再把 `obs-plugins` 文件夹中的文件，复制到 OBS 安装目录的 `obs-plugins` 文件夹中；
4. 完全退出并重新启动 OBS。

### macOS 安装

1. 下载 `obs-multi-rtmp-x.x.x.x-macos-universal.pkg`；
2. 双击 pkg 文件按提示安装即可；
3. 重启 OBS。

> 提示：安装完成后，如果 OBS 顶部菜单没有出现 "停靠窗口 -> 多路推流"，说明插件没装成功，检查目录是否放对。

## 二、使用插件

1. 重启 OBS Studio 后，菜单栏点击 **停靠窗口 → 多路推流**，打开多路推流面板；
2. 在推流面板中，**每添加一个平台就新增一路输出**，填入对应平台的**推流地址（RTMP URL）和串流密钥**；
3. 常规设置里勾选"启动流时自动启动所有输出"，可以实现一键同时开播；
4. 正式开播时，点击 OBS 的"开始直播"，所有配置好的输出会同时推流。

各平台推流地址获取位置：

| 平台 | 推流设置入口 |
|---|---|
| B 站 | 直播中心 → 我的直播间 → 推流设置 |
| 抖音 | 直播伴侣/创作者服务中心 → 直播设置 |
| 视频号 | 微信视频号助手 → 直播管理 → 推流地址 |
| YouTube | YouTube Studio → 直播 → 直播设置 |

## 三、常见问题

### 1. 推流认证失败（401/403）

- 检查推流地址和密钥是否**从平台直播间实时复制**（部分平台的密钥会定期失效）；
- 确认填的是 RTMP 地址而不是播放地址；
- 部分平台要求推流协议版本，如 B 站新推流地址带 `?streamtype=...` 参数，要完整复制。

### 2. 某一路卡顿、其他路正常

- 大概率是**上行带宽不足**：多路推流的总码率 = 各平台码率之和，建议把每路码率控制在 3000-4500kbps，总码率不超过上行带宽的 80%；
- 可对不同平台设置不同码率：画质要求高的平台给高码率，短视频平台可以适当降码率。

### 3. 插件不生效/找不到停靠窗口

- OBS 版本太旧或太新与插件不兼容，确认下载的是对应 OBS 版本的最新插件；
- Windows 安装时 `data` 和 `obs-plugins` 两个目录都要放，只放一个不会生效。

### 4. 延迟问题

- 多路推流比单路多一跳编码/上传，整体延迟会略增，属正常现象；
- 检查 OBS 的"输出 → 输出模式"是否选了高级，编码器建议用硬件编码（NVENC/Apple VT），CPU 占用更低、延迟更稳定。

## 四、进阶建议

- **带宽规划**：家用宽带上行一般 10-30Mbps，三路 1080p 推流（每路约 4500kbps）总码率约 13.5Mbps，务必留足余量；
- **备路**：可以把一路配成低码率（如 720p/2000kbps）作为备用，主平台出问题时有兜底；
- **配合 OBS 多场景**：不同平台想显示不同画面（如去掉平台水印），可以按场景切换，多路输出各自绑定不同场景。

## 总结

多流推送的核心就三步：**装插件 → 每平台填一路推流地址 → 一键同时开播**。剩下的主要工作是带宽规划和码率分配，把这两个控制好，多平台直播就能稳定跑起来。
