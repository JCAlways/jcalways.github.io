RTMP（Real-Time Messaging Protocol）是目前直播推流最常用的协议，OBS、FFmpeg 等工具都支持向 RTMP 服务器推流。本文介绍如何使用开源的 `smart_rtmpd` 快速搭建一个**本地 RTMP 推流服务器**，配合 OBS 即可实现多端直播推流。

> [官方网站](https://github.com/superconvert/smart_rtmpd?tab=readme-ov-file)

# 下载服务端软件

> 下载 `rtmpd.zip` 文件

[rtmpd.zip](https://github.com/superconvert/smart_rtmpd/releases)

`smart_rtmpd` 是一个跨平台（Windows / Linux / Mac）的 RTMP 流媒体服务器，支持：

- 直播流推流与转发
- HLS / HTTP-FLV 拉流
- 按需转码与录制
- 简单易用的 Web 管理界面

# 解压运行

- 解压 `rtmpd.zip` 文件
  - 然后解压 `smart_rtmpd_win.zip` 文件夹
  - 运行 `smart_rtmpd.exe` 重新
  - 点击 启动 即可

启动后服务默认监听 `1935` 端口（RTMP 标准端口），Web 管理界面默认端口为 `8080`（以程序提示为准），通过浏览器访问即可管理推流与拉流地址。

# OBS 推流配置

在 OBS 中配置推流地址，即可向本机 RTMP 服务器推流：

1. 打开 OBS，点击「设置」→「直播」
2. 服务类型选择**自定义**
3. 服务器地址填写：`rtmp://127.0.0.1:1935/live`
4. 串流密钥填写一个自定义的名称，如：`test`（作为流的标识）
5. 点击「开始推流」

推流完成后，可通过以下地址拉流验证：

- **HTTP-FLV**：`http://127.0.0.1:8080/live/test.flv`
- **HLS**：`http://127.0.0.1:8080/live/test.m3u8`

> 提示：如需将流推送到公网或其他设备观看，需要把服务器部署到公网主机，并在防火墙开放 `1935` 与 `8080` 端口。
